# 2026年秋课程网站

[课程网站](https://song17122328.github.io/cloud-ai-2026/)提供课程安排、项目要求、评分细则和教学资料。课程通知与作业提交通过Canvas管理。

## 课程安排

- 第3周：完整项目任务、评分要求与基础微调。
- 第7周：联邦对照、规模扩展与结果分析。
- 第8周与第12周：无服务器计算、量子机器学习案例演示。
- 第13教学周最后一天：通过Canvas一次提交项目及汇报材料。
- 第14教学周周一：项目汇报。
- 考核：考勤10%、项目实验与材料70%、项目汇报20%。

## 网站维护

`index.html`为首页，`files/`存放教学大纲、评分细则和讲义PDF。更新后提交并推送`main`，`Publish student course website`工作流通过GitHub Pages发布。

仓库跟踪学生网站、根目录`.gitignore`和`.github/workflows/pages.yml`。新增资料时同步首页链接及`.gitignore`允许条目。内部教学文件保留在本地。

当前讲义副本已排除过时的课程安排与作业要求。手动修改的实践PPT经核对并导出PDF后，更新相应下载文件。发布后检查Actions运行状态、课程周次、截止安排及下载链接。
