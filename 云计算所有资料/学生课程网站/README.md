# 2026年秋课程网站

[课程网站](https://song17122328.github.io/cloud-ai-2026/)提供课程安排、项目要求和教学资料。课程通知与作业提交通过Canvas管理。

## 课程安排

- 联邦微调综合项目：三个任务（大模型适配与推理 20 分、分布式训练与联邦学习 30 分、真实约束下的联邦挑战 20 分），在交大超算 π2.0 上完成。
- 第4周：课程作业指导及联邦实践。
- 第7周与第11周：无服务器计算、量子机器学习案例演示。
- 第13教学周最后一天：通过Canvas一次提交项目材料及汇报幻灯片。
- 第14、15周：课程作业汇报；第15周为课程作业汇报或大模型前沿。
- 考核：考勤10%、项目材料70%、项目汇报20%。

## 网站维护

`index.html`为首页，`files/`存放教学大纲、讲义PDF，以及课程作业及联邦实践资料（课程作业指导、联邦学习动手实践课件、任务书、超算使用手册、student_kit 材料包）。更新后提交并推送`main`，`Publish student course website`工作流通过GitHub Pages发布。

仓库跟踪学生网站、根目录`.gitignore`和`.github/workflows/pages.yml`。新增资料时同步首页链接及`.gitignore`允许条目。内部教学文件保留在本地。

常规授课讲义由当前定稿PPT通过PowerPoint导出为PDF，按授课进度发布（目前到Lecture 5），第一讲包含本学期课程信息。大模型基础参考讲义保留已清理旧作业要求的版本。实践讲义确认后再发布。发布后检查Actions运行状态、课程周次、截止安排及下载链接。
